# Smart Campus Management System

A full-stack MERN application that automates academic workflows through
responsive React.js interfaces connected to Node.js and Express.js RESTful APIs,
with data stored in MongoDB.

## Tech Stack
- **Frontend:** React.js, Tailwind CSS, Axios
- **Backend:** Node.js, Express.js, RESTful APIs
- **Database:** MongoDB

## Features
- Automated academic workflow management
- Responsive, reusable React components
- REST API integration between frontend and backend
- CRUD operations backed by MongoDB

## Getting Started
1. Clone the repo: `git clone <your-repo-url>`
2. Install dependencies in both `client` and `server` folders: `npm install`
3. Create a `.env` file in `server` with your MongoDB URI and port
4. Run the backend: `npm start`
5. Run the frontend: `npm start`
